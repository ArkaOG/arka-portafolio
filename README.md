# ARKA | Portafolio Digital

Sitio web estático creado con HTML, CSS y JavaScript a partir de la planeación del Entregable 1 de Arquitectura de Información y Diseño.

## Verlo en tu computadora
Abre `index.html` en tu navegador. Para probarlo con servidor local, ejecuta `python -m http.server 8000` desde esta carpeta y abre http://localhost:8000.

## Antes de publicar
1. Sustituye las seis imágenes SVG de muestra y los textos de proyectos por evidencias reales. Las tarjetas actuales están identificadas como MUESTRA.
2. Edita `CONTACT_EMAIL` en `script.js` con un correo de contacto público. El formulario usa `mailto:` y requiere una aplicación de correo configurada; no envía mensajes por sí solo.
3. Reemplaza el enlace genérico de YouTube por el de tu canal y confirma el enlace de Twitch.
4. Revisa ortografía, contenido y funcionamiento en celular y escritorio.

## Publicación gratuita en GitHub Pages
1. Crea un repositorio público, por ejemplo `arka-portafolio`.
2. Sube el contenido de esta carpeta a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch, rama `main` y carpeta `/ (root)`.
4. Espera a que GitHub muestre la URL publicada y comprueba la navegación, filtros, imágenes y enlaces.
5. El dominio `arkaportafolio.com` es una propuesta, NO está registrado ni se ha verificado su disponibilidad. Un dominio propio suele tener costo. La URL gratuita de GitHub Pages puede utilizarse para la entrega.

## Recursos visuales
Las seis ilustraciones SVG de `assets/` fueron creadas específicamente como recursos conceptuales para esta plantilla. No son capturas de trabajos terminados.

## Estructura
Inicio, Sobre mí, Portafolio, Habilidades, Contenido/ARKA y Contacto. El menú y los filtros usan JavaScript; el sitio es adaptable a dispositivos móviles.
